    For government and regulated teams

    • Data residency. Models tagged AU region have a verified option that keeps inference in Australian data centres. Self-host models can be run entirely on infrastructure you control.
    • Country of origin. Each model shows where its lab is based. Some agencies restrict products from particular vendors. Check current PSPF directions before you buy.
    • Licences. Open weights are not all the same. MIT and Apache 2.0 have no usage caps. Mistral's licence excludes companies above a revenue threshold.
    • GST. Overseas AI providers charge GST to customers who are not GST registered. Registered businesses that quote an ABN are usually invoiced without it.

    How this page stays current

    • The exchange rate loads live from the European Central Bank feed each time you open the page. If that fails, the last saved daily rate is used.
    • A scheduled job refreshes the saved rate and closed-model API prices every day, and pulls the latest host prices for open models.
    • Every model links to its sources. If a number looks wrong, the source link is the place to check.
    • Builders can use the raw data directly: models.json, hardware.json, fx.json.
